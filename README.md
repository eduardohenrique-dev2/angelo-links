# angelo. Studio Digital — Links

Portal de bio independente, estático (sem Vite, Node ou build), para Vercel.

## Deploy
- GitHub: https://github.com/eduardohenrique-dev2/angelo-links
- Na Vercel: **Framework Preset: Other**, **Root Directory: ./**, **Build Command vazio**.
- Projeto Vercel previsto: **angelo-links-bio**.
- Os metadados canonical, og:url, og:image e twitter:image usam **https://angelo-links-bw57.vercel.app/** como endereço publicado. **Confira a URL exata no painel da Vercel antes de compartilhar**; se for diferente, atualize essas tags no index.html.

## Site principal
- https://angelo-delta.vercel.app/
- Orçamento: https://angelo-delta.vercel.app/?utm_source=instagram&utm_medium=bio#orcamento
- Projetos: https://angelo-delta.vercel.app/?utm_source=instagram&utm_medium=bio#projetos
- Links externos WhatsApp e Instagram são os já existentes no projeto.

## Arquivos
- `index.html`: HTML, CSS e JS inline; link da bio, tema, animações e compartilhar.
- `logo.svg`, `logo-light.svg` e `favicon.svg`: originais da marca.
- `og-cover.png`: preview 1200 x 630 em PNG.
- `vercel.json`: cleanUrls e cache de imagens.
- `robots.txt`: permite indexação.

O site principal não foi alterado neste envio.
